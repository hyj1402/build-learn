# BUILD & LEARN 개발 요청 관리 문서

이 문서는 새로운 개발 요청을 받을 때마다 **같은 파일을 계속 수정하는 단일 작업 요청서**입니다. 완료된 작업의 자세한 기록은 `docs/development/DEVELOPMENT_LOG.md`에 누적합니다.

## 현재 작업

### 기본 정보

- 작업 이름: 관리자 세션 시간 제한 보정
- 시작일: 2026-10-01
- 상태: 완료
- 참고 화면: `/admin`, `/login`, `src/proxy.ts`
- 작업 원칙: 30분 유휴·12시간 절대 만료를 서버에서 강제하되 현재 브라우저 세션만 종료하고, 실제 작성 활동을 서버 요청으로 전달해 작업 중 오판을 줄인다.

### 요청 배경

최초 구현은 마지막 활동 쿠키를 30분, 세션 시작 쿠키를 12시간 뒤 브라우저에서 삭제했습니다. 제한 시각에 도달하면 판정 근거가 먼저 사라져 오래된 세션을 새 세션처럼 초기화할 수 있었고, 기본 `signOut()` 범위가 다른 기기의 세션까지 종료하는 문제도 있었습니다. 장시간 글을 작성하면서 서버 요청이 없으면 실제 활동 중이어도 유휴 상태로 오인할 수 있어 함께 보정합니다.

### 추가할 것

- [x] 관리자 세션 상수와 시간 판정 함수를 공통 모듈로 분리
- [x] 키보드·포인터·스크롤 활동을 최대 5분 간격으로 서버에 알리는 공통 감시 컴포넌트
- [x] 가벼운 관리자 활동 신호 Route Handler

### 수정할 것

- [x] 추적 쿠키가 제한 시간보다 먼저 삭제되지 않도록 보관 기간 조정
- [x] 쿠키 일부 누락·손상도 만료로 판정
- [x] 자동·수동 로그아웃을 현재 세션 범위로 제한
- [x] 비로그인·수동 로그아웃·자동 만료 때 관리자 추적 쿠키 삭제
- [x] POST 활동 신호도 로그인 화면의 GET으로 안전하게 전환하도록 303 사용

### 삭제할 것

- 없음

### 하지 않을 것

- Supabase DB 스키마·RLS 변경
- Supabase Pro 전용 세션 제한 설정에 의존
- 공개 페이지 요청마다 인증 검사 추가

### 완료 조건

- 29분 유휴는 유지되고 30분부터 유휴 만료됨
- 활동 중이어도 세션 시작 후 12시간부터 절대 만료됨
- 신규 세션은 두 추적 쿠키가 모두 없을 때만 초기화됨
- 자동 만료가 다른 브라우저·기기의 세션을 종료하지 않음
- 실제 관리자 화면 활동 중에는 서버의 마지막 활동 시각이 주기적으로 갱신됨

### 작업 결과

- 추적 쿠키를 400일 동안 보관하되 쿠키의 만료 시각이 아니라 저장된 서버 타임스탬프 차이로 30분·12시간을 판정합니다. 한쪽 쿠키만 없거나 값이 손상된 경우도 만료 처리합니다.
- 자동·수동 로그아웃은 `scope: "local"`로 현재 세션만 종료하고, 관리자 시간 쿠키도 함께 삭제합니다. 인증되지 않은 활동 신호 POST 요청은 303으로 로그인 GET 화면에 연결됩니다.
- `AdminSessionActivity`가 실제 키보드·포인터·스크롤 활동을 최대 5분에 한 번 `/admin/session/activity`로 전달합니다. 30분간 정말 활동이 없으면 현재 보호 화면을 새로 요청해 서버 Proxy가 로그아웃을 수행합니다.
- 시간 판정 함수의 신규·29분·30분·12시간·쿠키 누락·손상 시나리오를 직접 실행했고, 비로그인 POST 활동 신호가 303과 추적 쿠키 삭제 헤더를 반환하는 것도 확인했습니다. 전체 ESLint, TypeScript, Prettier와 `git diff --check`를 통과했습니다. 프로덕션 빌드는 실행 중인 개발 서버가 `.next/trace-build`를 점유해 Windows `EPERM`으로 시작 단계에서 중단됐습니다.

- Log 상세 전체 폭을 820px, 실제 본문 읽기 열을 680px로 제한하고 제목·요약·발행일·예상 읽기 시간·태그 순서로 정보 위계를 정리했습니다.

- 제목 영역의 그라데이션·카드 그림자와 `h2` 네 가지 순환색을 제거했습니다. 인용·인라인 코드·표·기본 Callout은 무채색으로 바꾸고, warning·success처럼 의미가 있는 상태색만 남겼습니다.
- 데스크톱 브라우저에서 글 영역 820px·본문 680px, 모바일 브라우저에서 본문 17px·줄간격 32.3px로 표시되는 것을 확인했습니다. 두 화면 모두 가로 넘침과 콘솔 오류가 없었고 키보드 본문 바로가기 링크도 정상 표시됐습니다.
- 다크 모드는 새 스타일이 기존 `--background`, `--foreground`, `--muted`, `--line`, 의미색 변수만 참조하도록 구성해 기존 테마 토큰을 그대로 따릅니다.
- `npm run lint`, `npm run type-check`, `npm run build`를 통과했습니다. 최종 문서 반영 후 `npm run format:check`를 재실행합니다.
