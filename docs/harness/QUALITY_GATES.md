# 완료 조건

## 필수 자동 검증

```bash
npm run lint
npm run type-check
npm run format:check
npm run build
```

모든 명령이 통과해야 작업 완료로 판단합니다. 실패한 검증이 있다면 원인과 영향을 작업 결과에 기록합니다.

## 변경 검토

- 요청한 기능과 직접 관련된 파일만 변경했는지 확인합니다.
- 새로운 오류, 경고, 타입 문제가 없는지 확인합니다.
- 비밀키, 토큰, 개인 정보가 Git diff에 포함되지 않았는지 확인합니다.
- 링크, 경로, 문서 설명이 실제 코드와 일치하는지 확인합니다.

## UI 변경 시 추가 검증

- 데스크톱과 모바일 화면을 확인합니다.
- 키보드 탐색과 기본 접근성을 확인합니다.
- 브라우저 콘솔 오류와 가로 넘침이 없는지 확인합니다.
