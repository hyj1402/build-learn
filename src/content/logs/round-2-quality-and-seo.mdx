## 작업 전 상태

카테고리를 선택한 뒤 검색하면 카테고리가 사라졌고, 데이터에는 존재하지만 화면에서 사용할 수 없는 태그와 데모 기능이 있었습니다. About과 Contact도 내용이 부족했습니다.

## 요청한 내용

교차 점검에서 발견된 기능 누락과 유지보수 문제를 고치고, 검색·공유·키보드 사용·반응형 화면까지 기본 품질을 높였습니다.

## 문제 원인

검색할 때 새 URL을 만들면서 기존 쿼리스트링을 복사하지 않았습니다. 일부 타입과 데이터 함수는 먼저 만들어졌지만 이를 사용하는 화면이 아직 연결되지 않았습니다.

## 변경한 내용

### 추가

- Log 태그 필터
- embed, link, download 프로젝트 데모 UI
- 프로젝트와 로그 썸네일
- Contact Form UI와 About 전체 섹션
- Open Graph, Twitter metadata, sitemap, robots, 404
- 키보드 포커스와 본문 바로가기 링크
- Prettier와 초보자 학습 가이드

### 수정

- 검색할 때 기존 카테고리와 태그 조건을 유지
- 태블릿 2열, 모바일 1열 반응형 레이아웃
- 읽기 어려웠던 압축 코드 포맷

### 삭제

- 실제 기능 없이 남아 있던 정적 Contact 안내만의 구성

## 왜 이렇게 변경했나

필터 상태를 URL에 모두 남기면 새로고침과 링크 공유 뒤에도 같은 결과를 볼 수 있습니다. 공통 데이터 구조는 유지하면서 화면이 빠진 부분만 연결해 불필요한 구조 변경을 피했습니다.

## 초보자가 알아둘 점

URL의 `?category=web&q=Next.js` 부분을 쿼리스트링이라고 합니다. 검색어를 추가할 때 기존 값을 복사한 뒤 필요한 값만 바꿔야 여러 필터가 함께 동작합니다.
