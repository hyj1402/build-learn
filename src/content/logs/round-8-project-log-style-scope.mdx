## 작업 전 상태

Log 상세을 위해 만든 파랑·보라·초록·앰버 색상이 공용 `.mdx-content` 선택자에 들어 있었습니다. Project와 Log가 같은 MDX 렌더러를 사용하므로 Project 상세 제목과 코드·표·안내 상자에도 Log 색상이 적용됐습니다.

<InputBox label="수정 범위">
  컴포넌트 구조는 바꾸지 않고 CSS 선택자의 적용 범위만 Project와 Log로 분리합니다.
</InputBox>

## 원인

CSS 선택자에 `.log-detail` 조건이 없었습니다. 브라우저는 해당 요소가 Project인지 Log인지 알 수 없고 `.mdx-content`라는 공통 클래스만 보고 같은 규칙을 적용했습니다.

> 공용 구조와 페이지 전용 디자인은 선택자의 범위로 구분해야 합니다.

## 변경한 내용

### Project 상세 기본 톤

- `h2`, 목록, 체크박스, 인용, 인라인 코드, 표를 검정·흰색·주황 톤으로 복원
- Callout과 InputBox도 주황 포인트 하나만 사용
- 코드 블록, 체크박스, 표 같은 공용 가독성 기능은 유지

### Log 상세 에디토리얼 톤

- `.log-detail` 안에서만 네 가지 구역 제목 색상 적용
- 파랑 메모, 보라 인용·정보, 초록 완료, 앰버 주의 색상 유지
- Log의 인라인 코드 색상이 어두운 코드 블록 내부까지 침범하지 않도록 별도 예외 추가

<Callout title="초보자 메모" tone="note">
  `.log-detail .mdx-content h2`는 `log-detail` 안쪽의 `mdx-content` 안쪽 `h2`만 선택합니다. 앞에
  조건을 하나 더 붙여 다른 페이지까지 스타일이 퍼지는 것을 막았습니다.
</Callout>
